# Fonte de entrada do aplicativo

base.html e a copia da fonte utilizada para gerar a entrega de 15/10/2026. E um insumo anterior as transformacoes de privacidade e monetizacao. Nao hospedar nem distribuir como versao final.

Execute node build.cjs na raiz para aplicar privacy/apply-privacy.cjs e os modulos frontend/. A entrega pronta esta em public/index.html. Os dados da demonstracao sao ficticios; os dados reais dos usuarios permanecem no Firebase, fora do Git.
